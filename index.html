Panel interno de "Aula Común"

Qué se corrigió aquí:

Antes, esta ruta dependía de que nadie conociera la URL. Ahora ya no depende de eso: aunque robots.txt siga listando /panel-admin/, encontrar la ruta ya no es suficiente para entrar. Cada vez que se carga esta página, el servidor (aquí simulado en el navegador, ya que este proyecto no tiene backend) debería revisar si existe una sesión válida con rol Administrador. Si no la hay, la respuesta correcta es 401/403 y redirigir al login — nunca mostrar el contenido primero.

Además, se agregó una medida detectiva: un registro de accesos (autorizados y fallidos), para poder notar si alguien está intentando entrar sin permiso — algo que robots.txt nunca pudo ofrecer.
